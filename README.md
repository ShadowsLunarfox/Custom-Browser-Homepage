# Lunar Start Page

A customizable browser new tab extension with search, shortcuts, themes, wallpapers, clocks, and draggable panels.

[GitHub Profile](https://github.com/ShadowsLunarfox) | [Project Repository](https://github.com/ShadowsLunarfox/Custom-Browser-Homepage)

</div>

## Main Functions

- Replaces the browser's default new tab page with a customizable homepage.
- Provides a central search bar with multiple search engine options.
- Supports search suggestions and search engine switching.
- Lets users add, edit, import, and export shortcut or bookmark cards.
- Allows draggable and resizable UI panels, including the clock, search area, and shortcuts panel.
- Includes multiple clock styles, such as digital and analog clocks.
- Offers light mode, dark mode, and several UI themes such as Default, Cartoon, Win98, WinXP, and Terminal.
- Supports customization of colors, font size, corner radius, transparency, blur, layout density, card spacing, and card height.
- Lets users choose built-in wallpapers or upload custom images, GIFs, and MP4 backgrounds.
- Includes multilingual support.
- Adds a right-click context menu option to save the current webpage to Lunar Start Page.
- Provides backup and restore tools for bookmarks and settings.
- Includes debug tools for checking browser compatibility and local storage data.

## Installation

### Download The Compressed File

1. Open the project repository:
   `https://github.com/ShadowsLunarfox/Custom-Browser-Homepage`
2. Click Code.
3. Click Download ZIP.
4. Extract the downloaded `.zip` file to a local folder.

### Load The Extension In Chrome Or Edge

1. Open the browser extension management page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the extracted project folder.
5. Open a new tab to use Lunar Start Page.
