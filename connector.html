Lunar Start Page

Windows media connector

This optional feature requires Windows 10 version 1809 or later. The homepage works without it. The extension never installs the connector automatically. Only run packages you trust, and review the release notes and file checksums.

Installation

  1. Download the separate Windows connector ZIP from the official Releases page and extract it. Development packages are marked draft; store packages are provided with the release. Project releases
  2. Open the music-note button on the homepage and find the extension ID in the player setup dialog. Developers can also find it at chrome://extensions or edge://extensions.
  3. Run Install.cmd from the extracted package. Store packages use their configured official IDs; development packages ask for your extension ID. Review the displayed installation path, IDs and current-user registration changes, then explicitly confirm.
  4. The installer copies the connector files and registers native messaging for Chrome/Edge for your Windows user only. Administrator access is not required. In the player, choose Agree and enable, grant the browser permission, then choose Check connection.

Files are installed at %LOCALAPPDATA%\LunarStart\MediaConnector. There is no startup entry or network listener. The connector runs on demand when an authorized, visible modern homepage connects.

The player follows Windows' current media selection automatically. Pause, seeking and progress depend on the source application's capabilities.

Disable and uninstall

  1. Open the help button beside the player title and choose Disable and revoke permission. This stops media access across all of this extension's tabs.
  2. Run Uninstall.cmd from the project, extracted package or installed connector folder. The project/package entry finds the default installation folder. Check the displayed path and enter YES to remove the connector's registration and installed files.

Uninstalling the connector keeps the extension, project source, bookmarks, wallpapers and homepage settings. The development build cache at native\windows-media\bin is separate from the installed connector and is not removed by the uninstaller.

Connection checks

  • If the player still says it is disconnected after installation, check that the installer used the ID shown in this extension's setup dialog. Reinstall with the correct ID if needed, return to the homepage and choose Check connection.
  • Granting browser permission alone does not install the connector or confirm a working connection. A connected player with no current media session is a normal idle state.
  • If the uninstaller reports that the connector is already uninstalled or has not been installed, there is nothing to remove. This is not an error.
