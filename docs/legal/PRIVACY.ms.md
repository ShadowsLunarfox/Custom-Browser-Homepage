# Dasar Privasi Lunar Start Page

Status: draf umum, belum berkuat kuasa sebagai dasar keluaran awam. Dikemas kini: 2026-10-31. Penerbit akan mengumumkan tarikh kuat kuasa semasa penerbitan.

## 1. Skop dan hubungan

Dasar ini meliputi antara muka baharu dan lama Lunar Start Page serta penyambung media Windows pilihan projek ini. Projek diselenggara oleh Lunarfox, nama GitHub ShadowsLunarfox. Pemprosesan bebas oleh pelayar, kedai, enjin carian dan pihak ketiga tertakluk pada dasar masing-masing.

Hubungi [sokongan projek](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues) untuk pertanyaan privasi. Ruang itu awam: jangan siarkan URL peribadi, butiran media, sandaran, kata laluan atau maklumat sensitif. Minta saluran peribadi yang sesuai sebelum berkongsi maklumat sedemikian.

## 2. Maklumat pada peranti

Nama dan URL pintasan yang disimpan/diimport, maklumat ikon, susunan dan pin, sejarah carian laman utama, bahasa, versi antara muka, rupa, susun atur, pilihan fungsi dan kertas dinding disimpan dalam storan setempat pelayar atau IndexedDB. Simpan melalui klik kanan membaca tajuk dan URL halaman yang anda pilih, bukan mengimbas keseluruhan sejarah pelayaran atau memantau semua tab secara berterusan.

Penyegerakan versi baharu/lama berlaku dalam profil pelayar yang sama, bukan melalui awan pembangun. Sambungan tidak memuat naik rekod ini melalui Chrome Storage Sync. Diagnostik dijana setempat; kandungannya keluar daripada antara muka setempat itu hanya jika anda menyalin, mengeksport atau menghantarnya.

## 3. Carian dan permintaan pihak ketiga

- Menghantar carian menghantar pertanyaan kepada penyedia dipilih. Cadangan dalam talian menghantar teks ditaip kepada penyedia cadangan berkaitan yang dikonfigurasi serta penyedia gantian apabila perlu. Mod berbilang enjin boleh menghubungi beberapa penyedia. Anda boleh mematikan cadangan.
- Perkhidmatan favicon Google mungkin menerima nama hos laman yang disimpan. Ikon, kertas dinding dan sumber jauh yang anda tetapkan menghubungi pelayan masing-masing.
- Carian imej menghantar imej yang anda pilih atau lepaskan secara nyata kepada Google. Selepas anda memulakan carian suara dan membenarkan akses pelayar, penyedia pengecaman pertuturan pelayar mungkin memproses audio. Sambungan tidak menyimpan rakaman.
- Tema Cartoon lama mungkin memuatkan Google Fonts. Kertas dinding terbina dalam adalah setempat; memilih fail sendiri tidak memuat naiknya kepada pembangun.

Penyedia lazimnya menerima alamat IP, masa permintaan dan maklumat rangkaian biasa, mungkin menggunakan kuki sendiri dan memproses data di negara lain mengikut dasar mereka. Metadata media Windows tidak dihantar kepada perkhidmatan tersebut. Pelayar, kedai dan GitHub juga mempunyai dasar bebas.

## 4. Widget media Windows pilihan

Widget dimatikan secara lalai. Sambungan memerlukan anda membaca penerangan, memilih Setuju dan dayakan, memberi kebenaran pemesejan natif pilihan, serta memasang penyambung secara berasingan. Tiada pemasangan automatik oleh sambungan.

Apabila widget didayakan dan kelihatan dalam laman utama baharu yang kelihatan, penyambung membaca sesi media Windows semasa: aplikasi, tajuk, artis, kulit, status, tempoh, kedudukan dan kawalan yang disokong. Data hanya digunakan untuk paparan/kawalan semasa dan disimpan sementara dalam memori setempat, bukan sejarah main balik, sandaran atau muat naik kepada pembangun. Arahan main balik berlaku melalui penggunaan kawalan anda.

Menyembunyikan widget atau meninggalkan halaman memutuskan klien itu dan memadam paparan media sementara; halaman aktif lain yang kelihatan mungkin kekal tersambung. Lumpuhkan dan tarik balik kebenaran menghentikan sambungan media semua tab sambungan ini. Versi lama tidak memuatkan widget.

Pemasang hanya mendaftarkan ID yang anda nyatakan atau ID pakej rasmi dalam tetapan pemesejan natif pengguna Windows semasa. Ia tidak membaca profil pelayar, membuat entri permulaan, mendengar port rangkaian atau memasang perisian tidak berkaitan.

## 5. Tujuan, perkongsian dan Penggunaan Terhad

Data digunakan untuk fungsi laman utama, carian, pintasan, rupa, diagnostik dan media yang diterangkan. Projek tidak mengendalikan pelayan akaun pengguna, analitik telemetri, profil iklan atau jualan data. Data tidak digunakan untuk iklan diperibadikan, keputusan kredit atau tujuan tidak berkaitan.

Penggunaan dan pemindahan maklumat API pelayar/Google oleh projek ini mematuhi Dasar Data Pengguna Chrome Web Store termasuk Penggunaan Terhad. Pemindahan terhad kepada fungsi didedahkan dan keadaan yang dibenarkan undang-undang serta perlu. Maklumat sokongan yang anda hantar secara sukarela digunakan untuk menjawab permintaan, keselamatan dan kewajipan undang-undang; kandungan sokongan awam disimpan oleh GitHub mengikut peraturannya.

## 6. Penyimpanan dan keselamatan

Pintasan, tetapan dan kertas dinding kekal sehingga diubah atau storannya dibuang. Pemadaman antara muka mungkin meninggalkan penanda pemadaman penyegerakan atau keadaan terdahulu, bukan mengosongkan semua storan. Media semasa bersifat sementara. Anda mengawal penyimpanan sandaran eksport.

Perkhidmatan rangkaian terbina dalam menggunakan HTTPS; pautan/sumber sendiri bergantung pada destinasi. Sambungan tidak mengenkripsi pintasan setempat atau sandaran eksport secara berasingan. Lindungi peranti, profil dan sandaran anda. Keselamatan mutlak tidak dapat dijamin.

## 7. Pilihan dan hak

Anda boleh mengedit/memadam item, mengurus sejarah carian, mematikan cadangan, menarik balik kebenaran dan mengeksport data. Pembersihan cache prestasi bukan pemadaman semua data. Untuk pembuangan lengkap, nyahpasang sambungan, kosongkan data setempat melalui pelayar dan padam sandaran sendiri.

Nyahpasang penyambung secara berasingan; membuang sambungan tidak memadam fail/pendaftaran Windowsnya. Folder bin projek ialah cache binaan yang berasingan.

Mengikut undang-undang berkaitan, hak mungkin termasuk akses, pembetulan, pemadaman, sekatan, bantahan, kebolehportan, penarikan persetujuan dan aduan kepada pihak berkuasa. Kebanyakan data hanya pada peranti anda; pembangun tidak boleh mengakses/memadamnya dari jauh tetapi boleh memberi panduan. Hubungi penyedia mengenai rekodnya. Penarikan tidak membatalkan pemprosesan terdahulu yang sah.

## 8. Kanak-kanak, perubahan dan bahasa

Projek tidak disasarkan khusus kepada kanak-kanak atau sengaja meminta maklumat peribadi mereka. Dapatkan bantuan penjaga apabila undang-undang tempatan memerlukannya. Perubahan penting pada tujuan/kebenaran akan dicerminkan di sini dengan notis/persetujuan tambahan apabila diwajibkan. Terjemahan bertujuan menyampaikan dasar sama; perbezaan tidak mengurangkan hak mandatori tempatan dan tiada bahasa ditetapkan mengatasi yang lain di semua bidang kuasa.
