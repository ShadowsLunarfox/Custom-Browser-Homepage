# Lunar Start Page 私隱政策

## 1. 適用範圍同聯絡方法

本政策適用於 Lunar Start Page 新版、舊版介面，同埋本項目提供嘅可選 Windows 媒體連接器。項目由 Lunarfox（GitHub 用戶名 ShadowsLunarfox）維護。瀏覽器、商店、搜尋引擎同其他第三方自行處理資料嘅活動，適用佢哋各自嘅政策。

私隱問題可以透過[項目支援入口](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues)提出。呢度係公開地方，請唔好貼私人網址、媒體內容、備份、密碼或者敏感資料；如需私下溝通，請先要求提供合適渠道。

## 2. 儲存喺本機嘅資料

擴充功能會用瀏覽器本機儲存或 IndexedDB 保存你新增、匯入或更改嘅收藏名稱同網址、圖示資料、排序同置頂狀態、主頁搜尋記錄、語言、介面版本、主題、佈局、功能偏好同自訂桌布。右鍵儲存只會讀取你主動選擇儲存嗰一頁嘅標題同網址，唔會掃描全部瀏覽記錄或持續監察所有分頁。

新舊版同步只喺同一個瀏覽器設定檔內進行，唔係開發者雲端同步，亦唔會用 Chrome Storage Sync 上傳呢啲記錄。診斷結果喺本機產生；只有你主動複製、匯出或提交，內容先會離開相應嘅本機介面。

新版可選系統監察只會喺你啟用後申請瀏覽器嘅 system.cpu 同 system.memory 權限。共享採樣器大約每兩秒讀取整機 CPU 計數器同實體記憶體總量、可用量。勾選背景更新後，只要瀏覽器仍然執行，即使小工具隱藏或所有主頁關閉都會繼續讀取；冇勾選時只為可見主頁小工具採樣。只喺瀏覽器工作階段記憶體快取最新讀數，方便再打開時即時顯示，唔保留歷史、唔放入備份、唔上傳。唔會讀取處理程序清單或記憶體內容，唔需要原生連接器。停用或撤銷權限會停止採樣同清空快取。啟用、背景更新、可見性偏好同配置會儲存喺本機；退出瀏覽器會清空工作階段快取。

## 3. 搜尋同第三方連線

- 提交搜尋會將查詢送去所選服務。啟用網上建議時，輸入內容會送去相關已設定嘅建議服務，同埋有需要時嘅後備服務；多引擎模式可能連接多個服務。你可以喺設定關閉建議。
- Google 圖示服務可能收到已儲存網站嘅主機名稱。你指定嘅遠端圖示、桌布或其他資源會連接各自伺服器。
- 以圖搜尋會將你明確選擇或拖入該功能嘅圖片送去 Google。你主動開啟語音搜尋並授權後，瀏覽器嘅語音識別服務可能處理音訊；擴充功能唔會保留錄音。
- 舊版 Cartoon 主題可能載入 Google Fonts。內置桌布屬於本機檔案；選擇自己嘅桌布唔會上傳畀開發者。

第三方通常亦會收到 IP 位址、請求時間同一般網絡資料，可能使用自己嘅 Cookie，或者喺其他國家處理資料，並受各自政策約束。擴充功能唔會將 Windows 媒體資料送去呢啲服務。瀏覽器、商店同 GitHub 亦有各自嘅政策。

## 4. 可選 Windows 播放器

媒體小工具預設停用。請閱讀說明後主動啟用、授予可選原生通訊權限，同埋另外安裝 Windows 連接器。背景更新係說明視窗入面嘅獨立選項；之前只針對可見頁面嘅授權唔會自動啟用背景存取。

啟用後，連接器讀取 Windows 目前媒體嘅應用程式、標題、作者、封面、播放狀態、時長、位置同支援操作。勾選背景更新後，只要瀏覽器仍然執行，即使小工具隱藏或所有主頁關閉，都會繼續跟隨 Windows。最新狀態共享快取喺瀏覽器工作階段記憶體，再打開時可以即時顯示。唔保留播放歷史、唔放入備份、唔傳送畀開發者。播放操作只會回應你主動使用控制項。

隱藏小工具或離開主頁會斷開嗰個頁面並清空頁面顯示；明確啟用嘅背景連接可以繼續執行。關閉背景更新後，最後一個可見且已授權小工具離開時，連接器會斷開。停用並撤銷權限會停止所有分頁嘅媒體存取同清空快取。退出瀏覽器會清空工作階段快取。舊版頁面唔會載入小工具或啟動讀取；之前已啟用嘅背景工作可以繼續，直到停用。

安裝程式只為你明確提供或正式安裝包指定嘅 ID 註冊目前 Windows 用戶嘅原生通訊；唔讀取瀏覽器設定檔、唔建立開機啟動項目、唔監聽網絡連接埠，亦唔安裝無關程式。

## 5. 用途、分享同有限使用

資料只用於本政策說明嘅主頁、搜尋、收藏、外觀、診斷同媒體功能。項目冇開發者營運嘅用戶帳戶服務、遙測分析、廣告側寫或資料銷售服務，唔會用資料做個人化廣告、信貸評估或無關用途。

我哋對瀏覽器或 Google API 資料嘅使用同傳遞遵守 Chrome 線上應用程式商店用戶資料政策，包括 Limited Use 要求。第三方傳遞限於已說明功能，同法律容許而有需要嘅情況。你主動提交嘅支援資料只用於回應請求、安全同適用法律義務；公開支援內容由 GitHub 按其規則保留。

## 6. 保留時間同安全

收藏、設定同桌布會保留到你更改或清除其儲存。介面上刪除項目可能仍留下同步用嘅刪除記號或舊狀態，唔等於徹底清空全部儲存。目前媒體資料係暫存；匯出備份由你自行管理。

內置網絡服務使用 HTTPS；你指定嘅連結或資源則視乎目的地。擴充功能唔會為本機收藏或匯出備份另外加密，請保護裝置、瀏覽器設定檔同備份。任何軟件或第三方都無法保證絕對安全。

## 7. 選擇同權利

你可以編輯或刪除項目、管理搜尋記錄、關閉建議、撤銷權限同匯出資料。清理效能快取唔會清空全部用戶資料。要完整移除，請解除安裝擴充功能，用瀏覽器提供嘅方式清除本機資料，並自行刪除備份。

連接器須另外解除安裝；移除擴充功能唔會自動刪除佢嘅 Windows 檔案同註冊。工程 bin 係獨立建置快取，唔係已安裝嘅連接器。

按適用法律，你可能有查閱、更正、刪除、限制或反對處理、資料可攜、撤回同意同向主管機關投訴等權利。大部分資料只喺你部機，開發者無法遠端讀取或代為刪除，但可以提供操作協助。第三方保留嘅記錄請聯絡相應服務；撤回同意唔影響之前合法處理。

## 8. 兒童、變更同語言

本項目唔係專為兒童而設，亦唔會有意要求兒童提交個人資料；所在地法律有要求時，未成年人應取得監護人協助。資料用途或權限有重大變更時會更新政策，並按法律要求另行通知同取得同意。翻譯旨在表達同一內容，差異唔可以削弱當地強制性法定權利，亦唔預設任何語言喺所有地區優先。
