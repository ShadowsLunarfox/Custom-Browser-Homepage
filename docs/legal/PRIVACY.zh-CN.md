## 1. 适用范围与联系

本政策适用于 Lunar Start Page 的新版、旧版界面及本项目提供的可选 Windows 媒体连接器。项目由 Lunarfox（GitHub 用户名 ShadowsLunarfox）维护。政策不适用于浏览器、应用商店、搜索引擎或其他第三方服务自身的处理活动。

隐私问题可通过[项目支持入口](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues)提出。该入口是公开的，请勿提交私人网址、媒体内容、备份、密码或其他敏感信息；需要私下沟通时，请先请求提供适当渠道。

## 2. 本机保存的数据

为提供主页功能，扩展使用浏览器本地存储或 IndexedDB 保存你添加、导入或更改的收藏名称和网址、图标信息、排序和置顶状态、主页内搜索历史、语言、界面版本、主题、布局、功能偏好及自定义壁纸。右键保存只读取你主动保存页面的标题和网址，不扫描完整浏览历史，也不持续监视所有标签页。

新版与旧版的数据同步发生在同一浏览器资料中，不是开发者云端同步。扩展不使用 Chrome Storage Sync 上传这些记录。诊断结果只在本地生成；只有你主动复制、导出或提交时，相关内容才离开相应的本地界面。

新版可选系统监控仅在你启用后申请浏览器的 system.cpu 和 system.memory 权限。共享采样器约每两秒读取整机 CPU 计数器及物理内存总量、可用量。勾选后台更新后，只要浏览器仍在运行，即使组件隐藏或所有主页关闭也会继续读取；未勾选时仅为可见主页组件采样。只在浏览器会话内存中缓存最新读数，便于重新打开时立即显示，不保留历史、不写入备份、不上传。不读取进程列表或内存内容，无需原生连接器。停用或撤销权限会停止采样并清空缓存。启用、后台更新、可见性偏好及布局保存在本地；退出浏览器会清空会话缓存。

## 3. 搜索及第三方网络请求

- 提交搜索会把查询发送给所选搜索服务。启用在线建议时，输入内容会发送给相关建议服务，包括设置中选择的服务及必要的备用建议服务；多引擎模式可能联系多个服务。可以在搜索设置中关闭在线建议。
- 网站图标可能通过 Google 的图标服务获取，该服务会收到网站域名。你提供的远程图标、壁纸和其他资源地址会联系对应服务器。
- 以图搜图会把你明确选择或拖入该功能的图片提交给 Google 图片搜索。语音搜索在你主动启动并授予浏览器权限后，由浏览器的语音识别服务处理音频；扩展本身不保存录音。
- 旧版卡通主题可能从 Google Fonts 加载字体。内置壁纸来自安装包；选择本地壁纸不会把文件上传给开发者。

第三方服务通常也会收到 IP 地址、请求时间和普通网络请求信息，并可能使用自己的 Cookie 或在其他国家处理数据，其处理受各自政策约束。扩展不向上述服务发送 Windows 媒体元数据。浏览器、应用商店及 GitHub 的独立处理活动也适用其自身政策。

## 4. 可选 Windows 播放器

媒体组件默认停用。请阅读说明后主动启用、授予可选的原生通信权限，并单独安装 Windows 连接器。后台更新是说明弹窗中的独立选项，之前仅针对可见页面的授权不会自动启用后台访问。

启用后，连接器读取 Windows 当前媒体的应用、标题、作者、封面、播放状态、时长、位置及支持的操作。勾选后台更新后，只要浏览器仍在运行，即使组件隐藏或所有主页关闭也会继续跟随 Windows。最新状态共享缓存在浏览器会话内存中，方便重新打开时直接显示。不保留播放历史、不写入备份、不上传给开发者。播放操作仅响应你主动使用控件。

隐藏组件或离开主页会断开该页面并清空页面显示，明确启用的后台连接可继续运行。关闭后台更新后，最后一个可见且已授权的组件离开时，连接器会断开。停用并撤销权限会停止所有标签页的媒体访问并清空缓存。退出浏览器会清空会话缓存。旧版页面不加载该组件，也不启动读取；此前已启用的后台任务可继续运行，直到停用。

连接器安装器只注册你明确提供或正式安装包指定的扩展 ID，使用当前 Windows 用户的原生通信注册项；不读取浏览器配置文件，不创建开机启动项，不监听网络端口，不安装无关软件。

## 5. 用途、共享与有限使用

信息仅用于本政策说明的主页、搜索、收藏、外观、诊断及媒体功能。项目不提供开发者运营的用户账号、遥测分析、广告画像或用户数据销售服务，不将数据用于个性化广告、信贷评估或与所述功能无关的用途。

我们对通过浏览器或 Google API 获得的信息的使用和传递遵守 Chrome 网上应用店用户数据政策及有限使用要求。第三方传递限于已说明的功能所必需的请求，以及适用法律允许且必要的情形。你主动提交的支持信息仅用于处理请求、维护安全和履行适用法律义务；公开支持内容由 GitHub 按其规则保存。

## 6. 保留与安全

收藏、设置和壁纸等本地状态会保留到你更改、清除扩展存储或移除相关数据。界面删除可能留下用于同步的删除标记或历史状态，因此不等于彻底清空所有存储。当前媒体信息为临时数据。导出备份由你自行保管和删除。

内置网络服务使用 HTTPS，但你指定的链接或资源取决于相应服务。扩展不为本地收藏或导出备份额外提供独立加密；请保护设备、浏览器资料和备份。任何软件或第三方服务都无法保证绝对安全。

## 7. 你的选择与权利

你可以编辑或删除主页项目、管理搜索历史、关闭在线建议、撤销可选权限并导出数据。清理性能缓存不会清空所有用户数据。需要完整移除时，请卸载扩展并按浏览器提供的方式清除其本地数据，再自行删除导出的备份。

连接器须单独卸载；卸载扩展不会自动移除其 Windows 文件和注册项。工程中的 `bin` 是独立构建缓存，卸载已安装的连接器不等于删除工程文件。

根据适用法律，你可能享有访问、更正、删除、限制或反对处理、数据可携带、撤回同意以及向主管机关投诉等权利。大部分数据只在你的设备上，开发者无法远程读取或替你删除；可以提供操作协助。对第三方持有的数据，请联系相应服务。撤回同意不影响此前合法处理。

## 8. 儿童、变更与语言

本项目不专门面向儿童，也不主动要求儿童提交个人信息；未成年人应在所在地法律要求时取得监护人协助。隐私问题请通过上述入口联系。

如数据用途或权限发生实质变化，将更新本政策，并在适用法律要求时另行说明和征求同意。翻译旨在表达相同内容；任何版本差异均不得削弱当地法律赋予你的权利，不预设某一种语言在所有地区必然优先。
