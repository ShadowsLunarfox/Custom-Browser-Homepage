## 1. 対象と連絡先

本方針は Lunar Start Page の新版・旧版と、本プロジェクトの任意の Windows メディア接続プログラムに適用されます。管理者は Lunarfox（GitHub：ShadowsLunarfox）です。ブラウザー、ストア、検索サービスなどの独自の処理には各事業者の方針が適用されます。

お問い合わせは[プロジェクトサポート](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues)へお願いします。公開の場なので、私的な URL、メディア情報、バックアップ、パスワードなどを投稿しないでください。非公開の情報を共有する前に、適切な連絡方法をお尋ねください。

## 2. 端末上の情報

保存・インポートしたリンク名と URL、アイコン情報、順序・固定状態、ホームページ内の検索履歴、言語、画面バージョン、外観、配置、機能設定、独自の壁紙をブラウザーのローカルストレージまたは IndexedDB に保存します。右クリック保存は、利用者が保存を選んだページのタイトルと URL を読みます。閲覧履歴全体の走査や全タブの継続監視は行いません。

新版と旧版の同期は同じブラウザープロファイル内で行われ、開発者のクラウドを使用しません。Chrome Storage Sync でこれらを送信しません。診断はローカルで生成され、コピー・エクスポート・送信を選んだ場合にそのローカル画面の外に出ます。

新版の任意のシステムモニターは、有効化した後にのみ system.cpu と system.memory の権限を要求します。共有サンプラーは約2秒ごとに端末全体の CPU カウンターと物理メモリの合計・利用可能量を取得します。バックグラウンド更新を選ぶと、ブラウザーの動作中はウィジェットや全ホームページを閉じても継続し、選ばない場合は表示中のウィジェットに対してのみ取得します。再表示用の最新値だけをブラウザーセッションのメモリ内に保持し、履歴保存、バックアップ収録、アップロードはしません。プロセス一覧やメモリの内容は読み取らず、コネクターも不要です。無効化または権限の取り消しで取得を停止しキャッシュを消去します。有効・背景更新・表示の設定と配置を端末内に保存し、ブラウザー終了時にセッションキャッシュを消去します。

## 3. 外部サービスへの通信

- 検索を実行すると選択した事業者に検索語を送信します。候補表示を有効にすると、入力内容を関連する設定済みの候補サービスや必要な代替サービスに送ります。複数エンジンでは複数の事業者に接続することがあります。候補表示は設定で停止できます。
- Google のファビコンサービスに保存先のホスト名を送る場合があります。指定した外部アイコン、壁紙やリソースの URL はそのサーバーに接続します。
- 画像検索は明示的に選択・ドロップした画像を Google に送ります。音声検索は利用者の開始操作とブラウザーの許可後、ブラウザーの認識サービスが音声を処理することがあります。拡張機能は録音を保存しません。
- 旧版の Cartoon テーマは Google Fonts を読み込む場合があります。同梱壁紙はローカルであり、自分の壁紙を選んでも開発者へ送信されません。

外部事業者は通常、IP アドレス、時刻などの通信情報を受け取り、独自の Cookie を使用し、国外で処理する場合があります。それぞれの方針を確認してください。Windows のメディア情報をこれらのサービスに送ることはありません。ブラウザー、ストア、GitHub にも独自の方針があります。

## 4. 任意の Windows プレーヤー

メディアウィジェットは初期状態では無効です。説明を読み、明示的に有効化し、任意のネイティブメッセージング権限を許可してください。別途 Windows コネクターのインストールも必要です。バックグラウンド更新は説明画面の独立した選択肢です。以前の表示中ページに対する同意から自動で背景アクセスを有効にはしません。

有効化後、Windows の現在のアプリ、タイトル、アーティスト、画像、再生状態、長さ、位置、利用可能な操作を取得します。背景更新を選択すると、ブラウザーの動作中はウィジェットや全ホームページを閉じても追従します。共有の最新状態をブラウザーセッションのメモリ内に保持し、再表示時にすぐ表示できます。再生履歴の保存、バックアップ収録、開発者への送信は行いません。再生操作はユーザーがコントロールを使ったときだけ行います。

非表示やページを閉じると、そのページの接続と表示を消去しますが、明示的に有効化した背景接続は継続できます。背景更新が無効なら、最後の表示中の許可済みウィジェットが閉じるとコネクターを切断します。無効化と権限の取り消しで全タブのアクセスを停止しキャッシュを消去します。ブラウザー終了時もセッションキャッシュを消去します。旧版ページはウィジェットを読み込まず取得も開始しませんが、すでに有効な背景処理は無効化まで継続できます。

インストーラーは明示的に指定された ID または正式パッケージの ID だけを、現在の Windows ユーザーのネイティブ通信設定に登録します。ブラウザープロファイルの読み取り、自動起動項目、ネットワーク待受、無関係なソフトウェアのインストールは行いません。

## 6. 保持と安全

リンク、設定、壁紙は変更またはストレージ削除まで残ります。画面上で削除しても同期用の削除記録や以前の状態が残る場合があり、完全消去とは異なります。現在のメディア情報は一時的です。書き出したバックアップは利用者が管理します。

組み込みの通信は HTTPS を使用します。指定したリンクやリソースは接続先に依存します。ローカルのリンクや書き出したバックアップを拡張機能が別途暗号化することはありません。端末、プロファイル、バックアップを保護してください。絶対的な安全性は保証できません。

項目の編集・削除、検索履歴の管理、候補表示の停止、任意権限の撤回、データの書き出しができます。性能キャッシュの消去は全データ削除ではありません。完全に移除するには拡張機能をアンインストールし、ブラウザーでローカルデータを消去し、書き出したバックアップも自分で削除してください。

接続プログラムは別途アンインストールが必要です。拡張機能の削除だけで Windows のファイルや登録は消えません。プロジェクトの bin は別のビルドキャッシュです。
