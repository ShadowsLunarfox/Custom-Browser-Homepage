# Lunar Start Page 개인정보 처리방침

상태: 일반 초안이며 공개 배포용 방침으로 아직 시행되지 않았습니다. 최종 수정: 2026-11-01. 시행일은 공개 시 게시자가 안내합니다.

언어: [English](../../PRIVACY.md) · [简体中文](PRIVACY.zh-CN.md) · [繁體粵語](PRIVACY.yue.md) · [日本語](PRIVACY.ja.md) · [한국어](PRIVACY.ko.md) · [ไทย](PRIVACY.th.md) · [Bahasa Melayu](PRIVACY.ms.md)

## 1. 적용 범위와 문의

이 방침은 Lunar Start Page의 새 화면과 기존 화면, 프로젝트의 선택형 Windows 미디어 연결 프로그램에 적용됩니다. 관리자는 Lunarfox(GitHub: ShadowsLunarfox)입니다. 브라우저, 스토어, 검색업체 등의 독자적인 처리는 각 업체 방침에 따릅니다.

[프로젝트 지원](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues)에 문의할 수 있습니다. 공개 게시판이므로 사적인 URL, 미디어 내용, 백업, 비밀번호나 민감한 정보를 게시하지 마세요. 비공개 정보 공유가 필요하면 먼저 적절한 연락 방법을 요청하세요.

## 2. 기기에 저장하는 정보

저장·가져온 바로가기 이름과 URL, 아이콘 정보, 순서와 고정 상태, 홈 화면 검색 기록, 언어, 화면 버전, 테마, 배치, 기능 설정과 사용자 배경을 브라우저 로컬 저장소 또는 IndexedDB에 저장합니다. 우클릭 저장은 사용자가 저장하기로 한 페이지의 제목과 URL만 읽으며, 전체 방문 기록을 검색하거나 모든 탭을 계속 감시하지 않습니다.

새 화면과 기존 화면의 동기화는 같은 브라우저 프로필 안에서 이루어지며 개발자 클라우드를 사용하지 않습니다. Chrome Storage Sync로 이 기록을 업로드하지 않습니다. 진단은 로컬에서 생성되며 사용자가 복사·내보내기·제출하는 경우 해당 로컬 화면 밖으로 전달됩니다.

신버전의 선택형 시스템 모니터는 활성화한 후에만 system.cpu 및 system.memory 권한을 요청합니다. 공유 샘플러가 약 2초마다 기기 전체 CPU 카운터와 물리 메모리의 총량 및 사용 가능량을 읽습니다. 백그라운드 갱신을 선택하면 브라우저가 실행되는 동안 위젯을 숨기거나 모든 홈페이지를 닫아도 계속하며, 선택하지 않으면 표시 중인 위젯에 대해서만 읽습니다. 다시 열 때 즉시 표시하도록 최신 값만 브라우저 세션 메모리에 캐시하며 기록 저장, 백업 포함, 업로드는 하지 않습니다. 프로세스 목록이나 메모리 내용은 읽지 않고 커넥터도 필요하지 않습니다. 비활성화하거나 권한을 취소하면 수집을 중지하고 캐시를 지웁니다. 활성화·백그라운드·표시 설정과 배치를 로컬에 저장하며 브라우저를 종료하면 세션 캐시가 삭제됩니다.

## 3. 검색과 외부 요청

- 검색을 실행하면 선택한 검색업체로 검색어가 전송됩니다. 온라인 추천을 켜면 입력 내용이 관련 설정된 추천 서비스 및 필요한 대체 서비스에 전송됩니다. 다중 엔진 모드는 여러 업체에 연결할 수 있으며 추천을 끌 수 있습니다.
- Google 파비콘 서비스가 저장한 사이트의 호스트명을 받을 수 있습니다. 사용자가 지정한 외부 아이콘, 배경과 자원은 해당 서버에 연결합니다.
- 이미지 검색은 명시적으로 선택하거나 해당 기능에 끌어놓은 이미지를 Google에 보냅니다. 음성 검색을 시작하고 브라우저 권한을 허용하면 브라우저의 음성 인식 업체가 오디오를 처리할 수 있습니다. 확장 프로그램은 녹음을 보관하지 않습니다.
- 기존 Cartoon 테마는 Google Fonts를 불러올 수 있습니다. 기본 배경은 패키지에 포함되며 로컬 배경 선택은 개발자에게 업로드되지 않습니다.

외부 서비스는 일반적으로 IP 주소, 요청 시각 등 통신 정보를 받으며 자체 쿠키를 쓰거나 해외에서 처리할 수 있습니다. 각 업체 방침을 확인하세요. Windows 미디어 정보는 이 서비스들로 전송하지 않습니다. 브라우저, 스토어, GitHub의 독자 처리에도 각자 방침이 적용됩니다.

## 4. 선택형 Windows 플레이어

미디어 위젯은 기본적으로 비활성화되어 있습니다. 설명을 읽고 직접 활성화한 후 선택적 네이티브 메시징 권한을 허용해야 하며 Windows 커넥터를 별도로 설치해야 합니다. 백그라운드 갱신은 설명 창의 개별 선택 사항입니다. 이전의 표시 중인 페이지에 대한 동의로 백그라운드 접근이 자동 활성화되지는 않습니다.

활성화하면 Windows의 현재 앱, 제목, 아티스트, 표지, 재생 상태, 길이, 위치 및 지원하는 조작을 읽습니다. 백그라운드 갱신을 선택하면 브라우저 실행 중 위젯을 숨기거나 모든 홈페이지를 닫아도 계속 추적합니다. 최신 상태를 브라우저 세션 메모리에 공유 캐시하여 다시 열 때 즉시 표시합니다. 재생 기록 저장, 백업 포함, 개발자 전송은 하지 않습니다. 재생 조작은 사용자가 컨트롤을 사용할 때만 실행됩니다.

위젯을 숨기거나 홈페이지를 떠나면 해당 페이지의 연결과 표시를 지우지만 명시적으로 활성화한 백그라운드 연결은 유지될 수 있습니다. 백그라운드 갱신이 꺼져 있으면 마지막으로 표시 중인 허용된 위젯이 닫힐 때 커넥터가 연결 해제됩니다. 비활성화 및 권한 취소는 모든 탭의 접근을 중지하고 캐시를 지웁니다. 브라우저 종료 시 세션 캐시도 삭제됩니다. 구버전 페이지는 위젯을 로드하거나 수집을 시작하지 않지만 이미 활성화된 백그라운드 작업은 비활성화할 때까지 유지될 수 있습니다.

설치 프로그램은 명시한 ID 또는 공식 패키지의 ID만 현재 Windows 사용자용 네이티브 통신 설정에 등록합니다. 브라우저 프로필 읽기, 시작 프로그램 추가, 네트워크 포트 수신, 무관한 소프트웨어 설치를 하지 않습니다.

## 5. 목적, 공유와 제한적 사용

정보는 설명한 홈 화면, 검색, 바로가기, 외관, 진단과 미디어 기능에만 사용합니다. 개발자 운영 계정 서버, 원격 이용 통계, 광고 프로필, 데이터 판매 서비스는 없습니다. 맞춤 광고, 신용 평가 또는 무관한 목적에 사용하지 않습니다.

브라우저나 Google API에서 얻은 정보의 사용과 이전은 Chrome 웹 스토어 사용자 데이터 정책 및 Limited Use 요구사항을 따릅니다. 제3자 전달은 공개한 기능과 법적으로 허용되고 필요한 경우로 한정됩니다. 직접 보낸 지원 정보는 문의 처리, 보안과 법적 의무 이행에 사용하며 공개 지원 게시물은 GitHub 규칙에 따라 보관됩니다.

## 6. 보관과 보안

바로가기, 설정과 배경은 변경하거나 저장소를 제거할 때까지 남습니다. 화면에서 삭제해도 동기화 삭제 표시나 이전 상태가 남을 수 있으므로 완전한 저장소 삭제와 다릅니다. 현재 미디어는 일시적이며 내보낸 백업은 사용자가 관리합니다.

기본 통신은 HTTPS를 사용합니다. 사용자가 입력한 링크와 자원은 목적지에 따라 다릅니다. 로컬 바로가기나 내보낸 백업에 별도 암호화를 제공하지 않습니다. 기기, 프로필과 백업을 보호하세요. 절대적인 보안을 보장할 수는 없습니다.

## 7. 선택과 권리

항목 편집·삭제, 검색 기록 관리, 추천 끄기, 권한 철회와 데이터 내보내기가 가능합니다. 성능 캐시 정리는 모든 사용자 데이터 삭제가 아닙니다. 완전히 제거하려면 확장 프로그램을 제거하고 브라우저 기능으로 로컬 데이터를 지우며 백업도 직접 삭제하세요.

연결 프로그램은 별도로 제거해야 합니다. 확장 프로그램 제거만으로 Windows 파일·등록이 삭제되지는 않습니다. 프로젝트 bin은 별도의 빌드 캐시입니다.

적용 법률에 따라 열람, 정정, 삭제, 처리 제한·거부, 이동, 동의 철회와 감독기관 신고 등의 권리가 있을 수 있습니다. 대부분의 정보는 기기에만 있어 개발자가 원격 열람·삭제할 수 없지만 절차를 안내할 수 있습니다. 외부 업체의 기록은 해당 업체에 문의하세요. 철회는 이전의 적법한 처리에 영향을 주지 않습니다.

## 8. 아동, 변경과 언어

아동을 특별히 대상으로 하지 않으며 아동 개인정보를 의도적으로 요구하지 않습니다. 지역 법률상 필요하면 보호자의 도움을 받으세요. 목적·권한의 중대한 변경은 방침에 반영하며 필요한 고지·동의를 진행합니다. 번역은 동일한 내용을 의도하며 차이로 인해 강행법상 권리를 줄이지 않습니다. 특정 언어가 모든 국가에서 우선한다고 정하지 않습니다.
