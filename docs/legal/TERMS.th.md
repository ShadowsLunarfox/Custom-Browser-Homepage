# ข้อกำหนดการใช้บริการ Lunar Start Page

สถานะ: ร่างทั่วไป ไม่กำหนดกฎหมายประเทศ องค์กรอนุญาโตตุลาการหรือศาลเฉพาะ แก้ไขล่าสุด: 2026-10-31 วันที่มีผลจะแจ้งเมื่อเผยแพร่

## 1. ขอบเขตและการยอมรับ

ข้อกำหนดอธิบายการใช้ส่วนขยายและตัวเชื่อมต่อ Windows ของโครงการที่ดูแลโดย Lunarfox (GitHub: ShadowsLunarfox) โปรดอ่านก่อนใช้ฉบับเผยแพร่ การยอมรับอย่างชัดแจ้งหรือใช้ต่อถือเป็นการยอมรับเฉพาะเมื่อเสนอข้อกำหนดอย่างเหมาะสมและกฎหมายรองรับ หากไม่ยอมรับ คุณหยุดใช้และถอนการติดตั้งได้

คุณต้องมีคุณสมบัติตามกฎหมายท้องถิ่นและได้รับความยินยอมผู้ปกครองเมื่อจำเป็น ติดต่อ[ฝ่ายสนับสนุนโครงการ](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues) นี่ไม่ใช่ข้อตกลงกับ Google, Microsoft หรือผู้ให้บริการอื่น

## 2. ฟังก์ชันและบุคคลภายนอก

ส่วนขยายมีหน้าแท็บใหม่ การค้นหา ทางลัด วอลเปเปอร์ นาฬิกา การจัดวางและการตั้งค่า พร้อมวิดเจ็ต Windows เสริมในหน้ารุ่นใหม่ ความพร้อมขึ้นกับเบราว์เซอร์ OS สิทธิ์และผู้ให้บริการ ไม่รับรองทุกฟังก์ชันในทุกเว็บไซต์ แอป อุปกรณ์หรือภาษา ไม่รับรองการทำงานต่อเนื่องหรือกำหนดอัปเดตตายตัว

การค้นหา การค้นด้วยภาพ การรู้จำเสียง ไอคอน ฟอนต์และเว็บไซต์ที่ลิงก์อาจเป็นของบุคคลภายนอก เนื้อหา ราคาและกฎเป็นของผู้ให้บริการ โปรดตรวจเงื่อนไข การให้ลิงก์ไม่ใช่การรับรองหรือประกันเนื้อหา

## 3. ตัวเชื่อมต่อและสิทธิ์

การควบคุมสื่อปิดเป็นค่าเริ่มต้น ต้องมี Windows ที่รองรับ ติดตั้งตัวเชื่อมต่อแยกและอนุญาต native messaging อย่างชัดเจน ไม่มีการติดตั้งอัตโนมัติหรือเปลี่ยนการเล่นก่อนคุณใช้ปุ่มควบคุม

วิดเจ็ตตามสื่อปัจจุบันของ Windows การหยุดชั่วคราวหรือเลื่อนตำแหน่งขึ้นกับแหล่งสื่อ สตรีมสดและบางแอปอาจไม่รองรับ คุณปิดใช้และถอนสิทธิ์ได้เสมอ การถอนส่วนขยายกับตัวเชื่อมต่อแยกกัน แคชบิลด์ก็แยกจากไฟล์ติดตั้ง

## 4. การใช้โดยชอบและเนื้อหาของคุณ

ปฏิบัติตามกฎหมายและสิทธิ์ผู้อื่น ห้ามใช้ในการเข้าถึงโดยไม่ได้รับอนุญาต กระจายมัลแวร์หรือรบกวนระบบที่ผิดกฎหมาย ข้อนี้ไม่จำกัดการวิจัย ทดสอบหรือการใช้อื่นที่ชอบด้วยกฎหมายและสัญญาอนุญาต เพิ่มภาพ วิดีโอ ไอคอน ลิงก์หรือวัสดุที่คุณมีสิทธิ์ใช้และเคารพสัญญาอนุญาตเท่านั้น

คุณคงสิทธิ์ในเนื้อหาของตน การเก็บในเครื่องไม่โอนกรรมสิทธิ์ให้ผู้พัฒนาหรือเป็นการอนุญาตเผยแพร่หรือส่งผลงานให้โครงการโดยอัตโนมัติ อย่าส่งความลับหรือสำรองส่วนตัวในพื้นที่สนับสนุนสาธารณะ

## 5. สัญญาอนุญาตโอเพนซอร์สมีผลก่อน

สิทธิ์และหน้าที่ในการคัดลอก แก้ไขและแจกจ่ายซอร์สเป็นไปตาม [GNU GPL v3](../../LICENSE) ในคลังโครงการ ข้อกำหนดนี้ไม่เพิ่มข้อจำกัดหรือให้สละสิทธิ์เหล่านั้น การแจกจ่ายซอร์ส การรับประกันและความรับผิดยังเป็นไปตามสัญญาอนุญาตในส่วนที่ใช้บังคับ

ฟอนต์ ไอคอน เครื่องหมายการค้า วอลเปเปอร์และสื่อภายนอกอาจมีสิทธิ์แยก การรวมไว้ไม่ได้ทำให้ทุกชิ้นเป็น GPL หรือได้รับการรับรองจากบุคคลภายนอก เนื้อหาของคุณก็ไม่กลายเป็น GPL เพียงเพราะใช้ส่วนขยาย

## 6. ความเป็นส่วนตัว สำรองและความปลอดภัย

อ่าน[นโยบายความเป็นส่วนตัว](PRIVACY.th.md) และดูแลอุปกรณ์ โปรไฟล์และสำรองข้อมูล สำรองสิ่งจำเป็นก่อนล้างข้อมูล ติดตั้งใหม่หรือเปลี่ยนโปรไฟล์ ผู้พัฒนาไม่มีสำเนาคลาวด์ที่จะรับประกันการกู้คืนข้อมูลในเครื่อง

ใช้แหล่งเผยแพร่ที่เชื่อถือ ตรวจบันทึกรุ่นและ checksum ที่ให้ไว้ อย่าปิดระบบป้องกันความปลอดภัยเพื่อใช้โครงการนี้

## 7. การเปลี่ยนแปลง การเลิกใช้และการสนับสนุน

ฟังก์ชันอาจเปลี่ยนหรือยุติเพื่อบำรุงรักษา ความปลอดภัย นโยบายเบราว์เซอร์หรือเหตุจากภายนอก การเปลี่ยนข้อกำหนดสำคัญควรแจ้งอย่างเหมาะสมและขอความยินยอมใหม่เมื่อกฎหมายกำหนด การแก้โดยไม่แจ้งไม่ตัดสิทธิ์ตามกฎหมายย้อนหลัง

คุณหยุดใช้ ถอนสิทธิ์หรือถอนการติดตั้งได้ทุกเมื่อ การยุติแจกจ่ายหรือสนับสนุนที่จำเป็นและชอบด้วยกฎหมายไม่เพิกถอนสิทธิ์โอเพนซอร์สที่ได้รับแล้ว โครงการปัจจุบันไม่สัญญาบริการหรือสมาชิกแบบเสียเงิน การคิดเงินในอนาคตต้องแจ้งแยก ไม่รับรองเวลาตอบหรือระดับบริการ

## 8. การรับประกันและความรับผิด

ในขอบเขตที่กฎหมายและสัญญาอนุญาตยอมให้ ซอฟต์แวร์ให้ตามสภาพโดยไม่มีคำรับรองเพิ่มเติมด้านความพร้อม ความถูกต้อง ความเหมาะสมหรือความต่อเนื่อง ความรับผิดเรื่องข้อมูลหาย ความล้มเหลวภายนอกหรือความเสียหายอื่นจำกัดได้เฉพาะที่กฎหมายอนุญาต

ไม่ยกเว้นความรับผิดที่กฎหมายห้ามยกเว้น รวมถึงการรับประกันตามกฎหมาย การเยียวยาผู้บริโภค การฉ้อโกงหรือสิทธิ์คุ้มครองอื่น ไม่กำหนดเพดานชดเชยตามอำเภอใจหรือให้สละสิทธิ์ผู้บริโภคที่บังคับใช้

## 9. กฎหมาย ข้อพิพาทและภาษา

ร่างนี้ไม่เลือกกฎหมายประเทศ อนุญาโตตุลาการบังคับหรือศาลต่างประเทศเฉพาะ ข้อพิพาทอยู่ภายใต้กฎหมายที่ใช้บังคับและองค์กรที่มีอำนาจ สิทธิ์ผู้บริโภคท้องถิ่นที่สละไม่ได้ยังคงอยู่ การติดต่อสนับสนุนก่อนไม่จำกัดสิทธิ์ร้องเรียน ฟ้องหรือขอเยียวยาอื่น

หากข้อหนึ่งไม่มีผล ส่วนอื่นใช้ได้เท่าที่กฎหมายอนุญาต ความต่างของคำแปลไม่ลดสิทธิ์บังคับและไม่กำหนดให้ภาษาอังกฤษหรือภาษาอื่นมีอำนาจเหนือในทุกพื้นที่
