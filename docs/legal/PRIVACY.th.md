# นโยบายความเป็นส่วนตัวของ Lunar Start Page

สถานะ: ร่างทั่วไป ยังไม่มีผลเป็นนโยบายฉบับเผยแพร่สู่สาธารณะ แก้ไขล่าสุด: 2026-11-01 ผู้เผยแพร่จะแจ้งวันที่มีผลเมื่อเผยแพร่จริง

## 1. ขอบเขตและการติดต่อ

นโยบายนี้ครอบคลุมหน้าแบบใหม่และแบบเดิมของ Lunar Start Page และตัวเชื่อมต่อสื่อ Windows เสริมของโครงการ ผู้ดูแลคือ Lunarfox (GitHub: ShadowsLunarfox) การประมวลผลของเบราว์เซอร์ ร้านค้า ผู้ให้บริการค้นหา และบุคคลภายนอกอยู่ภายใต้นโยบายของแต่ละราย

ติดต่อ[ฝ่ายสนับสนุนโครงการ](https://github.com/ShadowsLunarfox/Lunar-Start-Page/issues)ได้ พื้นที่ดังกล่าวเป็นสาธารณะ อย่าโพสต์ URL ส่วนตัว รายละเอียดสื่อ สำรองข้อมูล รหัสผ่านหรือข้อมูลอ่อนไหว หากต้องส่งข้อมูลส่วนตัว ให้ขอช่องทางที่เหมาะสมก่อน

## 2. ข้อมูลในอุปกรณ์

ส่วนขยายบันทึกชื่อและ URL ทางลัดที่เพิ่มหรือนำเข้า ข้อมูลไอคอน ลำดับและการปักหมุด ประวัติการค้นหาในหน้าแรก ภาษา รุ่นหน้าจอ ธีม การจัดวาง การตั้งค่าฟังก์ชัน และวอลเปเปอร์ไว้ในพื้นที่จัดเก็บของเบราว์เซอร์หรือ IndexedDB การบันทึกด้วยคลิกขวาอ่านชื่อและ URL ของหน้าที่คุณเลือก ไม่สแกนประวัติทั้งหมดหรือติดตามทุกแท็บอย่างต่อเนื่อง

การซิงก์ระหว่างสองหน้าจอเกิดภายในโปรไฟล์เบราว์เซอร์เดียวกัน ไม่ใช่คลาวด์ของผู้พัฒนา และไม่อัปโหลดผ่าน Chrome Storage Sync การวินิจฉัยสร้างในเครื่อง ข้อมูลจะออกจากหน้าจอภายในนั้นเมื่อคุณเลือกคัดลอก ส่งออก หรือส่งให้ผู้อื่น

ตัวตรวจสอบระบบเสริมในรุ่นใหม่จะขอสิทธิ์ system.cpu และ system.memory หลังคุณเปิดใช้งานเท่านั้น ตัวอ่านร่วมจะอ่านตัวนับ CPU ทั้งเครื่องและหน่วยความจำกายภาพทั้งหมดกับที่ว่างประมาณทุกสองวินาที หากเลือกอัปเดตในพื้นหลังจะทำงานต่อขณะเบราว์เซอร์ทำงาน แม้ซ่อนวิดเจ็ตหรือปิดหน้าแรกทั้งหมด หากไม่เลือกจะอ่านเฉพาะวิดเจ็ตที่มองเห็น เก็บเฉพาะค่าล่าสุดในหน่วยความจำเซสชันของเบราว์เซอร์เพื่อแสดงทันทีเมื่อเปิดใหม่ ไม่เก็บประวัติ ไม่รวมในข้อมูลสำรองและไม่อัปโหลด ไม่อ่านรายการโปรเซสหรือเนื้อหาในหน่วยความจำและไม่ต้องใช้ตัวเชื่อมต่อ การปิดใช้งานหรือเพิกถอนสิทธิ์จะหยุดอ่านและล้างแคช บันทึกตัวเลือกเปิดใช้งาน พื้นหลัง การแสดงผล และตำแหน่งไว้ในเครื่อง การปิดเบราว์เซอร์จะล้างแคชเซสชัน

## 3. การค้นหาและคำขอภายนอก

- การส่งคำค้นจะส่งไปยังผู้ให้บริการที่เลือก หากเปิดคำแนะนำออนไลน์ ข้อความที่พิมพ์จะถูกส่งไปยังผู้ให้บริการคำแนะนำที่เกี่ยวข้องตามการตั้งค่าและผู้ให้บริการสำรองเมื่อจำเป็น โหมดหลายเอนจินอาจติดต่อหลายราย คุณปิดคำแนะนำได้
- บริการ favicon ของ Google อาจได้รับชื่อโฮสต์ของเว็บไซต์ที่บันทึก ไอคอน วอลเปเปอร์และทรัพยากรภายนอกที่คุณระบุจะติดต่อเซิร์ฟเวอร์นั้น
- การค้นหาด้วยภาพส่งภาพที่คุณเลือกหรือวางในฟังก์ชันนี้ไปยัง Google หลังเริ่มค้นหาด้วยเสียงและอนุญาตสิทธิ์ เบราว์เซอร์อาจส่งเสียงให้บริการรู้จำเสียงประมวลผล ส่วนขยายไม่เก็บเสียงบันทึก
- ธีม Cartoon แบบเดิมอาจโหลด Google Fonts วอลเปเปอร์ที่รวมมากับส่วนขยายอยู่ในเครื่อง การเลือกไฟล์ของคุณไม่อัปโหลดให้ผู้พัฒนา

ผู้ให้บริการมักได้รับ IP เวลาและข้อมูลเครือข่ายปกติ อาจใช้คุกกี้ของตนและประมวลผลในต่างประเทศตามนโยบายของตน ส่วนขยายไม่ส่งข้อมูลสื่อ Windows ไปยังบริการเหล่านี้ เบราว์เซอร์ ร้านค้าและ GitHub มีนโยบายแยกต่างหาก

## 4. เครื่องเล่น Windows เสริม

วิดเจ็ตสื่อเริ่มต้นในสถานะปิด โปรดอ่านคำอธิบาย เลือกเปิดใช้งานและอนุญาตสิทธิ์การสื่อสารแบบเนทีฟ และติดตั้งตัวเชื่อมต่อ Windows แยกต่างหาก การอัปเดตในพื้นหลังเป็นตัวเลือกแยกในหน้าคำอธิบาย การยอมรับก่อนหน้าสำหรับหน้าที่มองเห็นจะไม่เปิดการเข้าถึงพื้นหลังโดยอัตโนมัติ

เมื่อเปิดใช้ ตัวเชื่อมต่อจะอ่านแอป ชื่อ ศิลปิน ปก สถานะเล่น ระยะเวลา ตำแหน่งและการควบคุมที่ Windows รองรับ หากเลือกพื้นหลังจะติดตามต่อขณะเบราว์เซอร์ทำงาน แม้ซ่อนวิดเจ็ตหรือปิดหน้าแรกทั้งหมด แคชเฉพาะสถานะล่าสุดร่วมกันในหน่วยความจำเซสชันเพื่อแสดงทันทีเมื่อเปิดใหม่ ไม่เก็บประวัติเล่น ไม่รวมในข้อมูลสำรองและไม่ส่งให้ผู้พัฒนา การเล่นจะเปลี่ยนเมื่อคุณใช้ตัวควบคุมเท่านั้น

การซ่อนวิดเจ็ตหรือออกจากหน้าแรกจะตัดการเชื่อมต่อและล้างการแสดงของหน้านั้น แต่การเชื่อมต่อพื้นหลังที่เปิดไว้อย่างชัดเจนอาจทำงานต่อ หากปิดพื้นหลัง ตัวเชื่อมต่อจะตัดเมื่อวิดเจ็ตที่มองเห็นและได้รับอนุญาตอันสุดท้ายปิดลง การปิดใช้และเพิกถอนสิทธิ์จะหยุดทุกแท็บและล้างแคช การปิดเบราว์เซอร์จะล้างแคชเซสชันด้วย หน้าเก่าไม่โหลดวิดเจ็ตหรือเริ่มอ่าน แต่งานพื้นหลังที่เปิดไว้ก่อนหน้าอาจทำต่อจนกว่าจะปิดใช้งาน

ตัวติดตั้งลงทะเบียนเฉพาะ ID ที่ระบุชัดเจนหรือ ID ในแพ็กเกจทางการใน native messaging ของผู้ใช้ Windows ปัจจุบัน ไม่อ่านโปรไฟล์เบราว์เซอร์ ไม่เพิ่มรายการเริ่มระบบ ไม่เปิดพอร์ตรับเครือข่าย และไม่ติดตั้งซอฟต์แวร์ที่ไม่เกี่ยวข้อง

## 5. วัตถุประสงค์และการเปิดเผย

ข้อมูลใช้กับหน้าแรก การค้นหา ทางลัด รูปลักษณ์ การวินิจฉัยและสื่อที่อธิบายไว้ โครงการไม่มีระบบบัญชีผู้ใช้ การวิเคราะห์การใช้งานจากระยะไกล โปรไฟล์โฆษณาหรือบริการขายข้อมูลของผู้พัฒนา ไม่ใช้เพื่อโฆษณาเฉพาะบุคคล ประเมินสินเชื่อหรือวัตถุประสงค์อื่น

การใช้และส่งต่อข้อมูล API ของเบราว์เซอร์หรือ Google ของโครงการนี้สอดคล้องกับนโยบายข้อมูลผู้ใช้ Chrome Web Store รวมถึง Limited Use การส่งต่อจำกัดเฉพาะฟังก์ชันที่แจ้งและกรณีจำเป็นที่กฎหมายอนุญาต ข้อมูลที่คุณส่งเพื่อขอความช่วยเหลือใช้ตอบคำขอ รักษาความปลอดภัยและทำตามหน้าที่กฎหมาย เนื้อหาสนับสนุนสาธารณะถูกเก็บโดย GitHub ตามกฎของบริการ

## 6. ระยะเวลาและความปลอดภัย

ทางลัด การตั้งค่าและวอลเปเปอร์คงอยู่จนแก้ไขหรือลบพื้นที่จัดเก็บ การลบผ่านหน้าจออาจเหลือเครื่องหมายลบเพื่อซิงก์หรือสถานะเดิม ไม่เท่ากับล้างข้อมูลทั้งหมด ข้อมูลสื่อปัจจุบันเป็นข้อมูลชั่วคราว สำรองที่ส่งออกอยู่ภายใต้การดูแลของคุณ

บริการเครือข่ายในตัวใช้ HTTPS ลิงก์หรือทรัพยากรที่คุณระบุขึ้นอยู่กับปลายทาง ส่วนขยายไม่เข้ารหัสทางลัดในเครื่องหรือไฟล์สำรองแยกเพิ่มเติม โปรดปกป้องอุปกรณ์ โปรไฟล์และสำรองข้อมูล ไม่สามารถรับประกันความปลอดภัยสมบูรณ์ได้

## 7. ทางเลือกและสิทธิ์

คุณแก้ไขหรือลบรายการ จัดการประวัติ ปิดคำแนะนำ ถอนสิทธิ์และส่งออกข้อมูลได้ การล้างแคชประสิทธิภาพไม่ได้ลบข้อมูลผู้ใช้ทั้งหมด หากต้องการลบครบ ให้ถอนส่วนขยาย ล้างข้อมูลภายในผ่านเบราว์เซอร์และลบไฟล์สำรองเอง

ต้องถอนตัวเชื่อมต่อแยก การลบส่วนขยายไม่ลบไฟล์และทะเบียน Windows ของตัวเชื่อมต่อ โฟลเดอร์ bin ของโครงการเป็นแคชบิลด์แยกต่างหาก

กฎหมายที่ใช้บังคับอาจให้สิทธิ์เข้าถึง แก้ไข ลบ จำกัดหรือคัดค้านการประมวลผล โอนย้าย ถอนความยินยอม และร้องเรียนหน่วยงาน ข้อมูลส่วนใหญ่อยู่บนอุปกรณ์เท่านั้น ผู้พัฒนาไม่สามารถเข้าถึงหรือลบจากระยะไกล แต่ให้คำแนะนำได้ ให้ติดต่อผู้ให้บริการสำหรับข้อมูลที่เขาถือครอง การถอนความยินยอมไม่กระทบการประมวลผลเดิมที่ชอบด้วยกฎหมาย

## 8. เด็ก การเปลี่ยนแปลงและภาษา

โครงการไม่ได้มุ่งที่เด็กโดยเฉพาะหรือจงใจขอข้อมูลส่วนบุคคลของเด็ก ให้ผู้ปกครองช่วยเมื่อกฎหมายท้องถิ่นกำหนด การเปลี่ยนวัตถุประสงค์หรือสิทธิ์ที่สำคัญจะปรับในนโยบาย พร้อมแจ้งและขอความยินยอมเพิ่มเติมเมื่อจำเป็น คำแปลมีเจตนาให้เนื้อหาเดียวกัน ความต่างไม่ลดสิทธิ์ตามกฎหมายบังคับ และไม่มีภาษาใดมีอำนาจเหนือทุกภาษาในทุกพื้นที่
